# BIOGLOW Quiz 2026 — SESI MacGyvers

Quiz interativo em HTML, CSS e JavaScript para treinamento da equipe na temporada FLL BIOGLOW.

## Recursos
- 40 questões de múltipla escolha
- 5 categorias: Biodiversidade e Tapete, Missões BIOGLOW, Regras do Robot Game, Estratégia e Situações-problema
- pontuação total de 50 pontos
- correção imediata com explicações
- barra de progresso
- resultado por categoria
- revisão final de respostas
- campo opcional para nome do aluno/equipe
- layout responsivo para celular, tablet e computador

## Como usar
Abra o arquivo `index.html` diretamente no navegador ou publique o repositório com GitHub Pages.

Projeto educacional da equipe SESI MacGyvers.
